How does React rendering and reconciliation work?

Practice This Question

Example answer

React schedules a render when state or props change, builds a new element tree, reconciles it with the previous tree, and commits the minimal DOM updates.

Expected answer points

  • State or prop change
  • Virtual DOM comparison
  • Commit phase

AI coaching tips

  • Mention keys and batching
  • Explain render versus commit
